# Tiny Transformer NPU — V0 reproduction

V0 reproduces nanoNPU before adding DFT or Transformer operations. It is not
complete until a fresh checkout passes `make sim && make pnr` and produces
new GDS, SPEF and post-route STA reports. See `docs/VALIDATION.md` for observed
results; the presence of upstream `Final/` files does not satisfy this gate.

## Baseline and scope

Upstream: https://github.com/Ammar-Wahidi/NPU

Pinned commit: `f876e8e236aed42e3ca4627ca8e43f8d44f1a086` (Apache-2.0).
The upstream history, license and constraints are retained. The physical CU has
a minimal fix that gates CONV launch with `exec_pulse` to prevent replay. This is a local
fork; no remote repository has been created or published.

The actual physical top is `Backend/openlane/RTL/npu_project_macro.sv` with a
**4×4 array, 64×32 synthesizable data memory and 32×32 instruction memory**.
Both simulation and physical implementation use `Backend/openlane/RTL`.
`verification/system/tb_npu_system_4x4.sv` adapts the upstream 4×4 testbench
to the fused CONV encoding and adds checks for one launch, four output rows
and stable shift control. It uses the 0x200 DMEM window. The README's 8×8 description and the separate 8×8 system testbench do
not describe this physical configuration.

## Requirements and commands

- Git and Python 3.10+ on the host.
- Docker running with at least 8 CPU cores and roughly 12 GB RAM for this trial.
  This is the observed environment, not a proven minimum requirement.
- Network access and disk space for the tool image and SKY130 PDK.

```sh
make setup
make doctor
make sim
make pnr
make artifacts
```

On machines without Git LFS, clone with filters disabled (archived binary
outputs remain pointers). This runner fetches and validates its required DEF
input independently:

```sh
git -c filter.lfs.required=false -c filter.lfs.process= -c filter.lfs.smudge= clone <your-fork-url>
```

The commands run in containers with only this checkout mounted at `/work`.
The physical image is pinned by digest. Simulation adds GNU make and GCC from
the exact nixpkgs commit used by LibreLane 3.0.5. This avoids a host EDA install.
The local `.venv/` used during investigation is not required by these commands.

`make sim` builds Verilator's timed simulation and runs two explicit random
seeds. Each seed must finish all nine upstream test cases, with 36 word
comparisons passing and none failing. A watchdog, missing summary, failure
message or simulator error makes the target fail even if `$finish` returned 0.
The testbench drives `npu_system_top` over UART; it does not verify the
OpenFrame pad wrapper or gate-level timing.

`make pnr` snapshots the current physical inputs into `build/attempts/<tag>`, applies
`physical/librelane/v0-overrides.json` and `standalone-overrides.json`,
and invokes the full LibreLane Classic flow on a 1,750 × 1,750 µm die.
The overrides remove the old
netlist-specific ECO insertion and its duplicate routing step. Automatic
design repair settings are retained, with post-global-route timing repair added
for the standalone floorplan. STA runs at most two corners concurrently.
All snapshot input hashes are recorded. It
downloads the PDK into `.cache/pdk`. Each attempt uses a fresh run tag. It
requires the flow to return successfully and checks for newly generated GDS,
SPEF and STA files before accepting the target. It does not use prebuilt
upstream GDS, DEF outputs or timing reports as replacement results.

Outputs:

| Path | Meaning |
| --- | --- |
| `build/sim/compile.log` | Compiler diagnostics, including upstream width warnings |
| `build/sim/seed-*.log` | UART tests and golden comparisons |
| `build/sim/results.json` | Successful simulation checks |
| `build/attempts/<tag>/runs/<tag>/` | Fresh synthesis, placement, CTS, routing and signoff state |
| `build/pnr-success.json` | Successful flow invocation receipt |
| `build/artifacts.json` | Artifact paths, sizes and SHA-256 hashes |

## Reproduction hazards found in upstream

1. The physical source set differs from the advertised 8×8 architecture.
2. `config.json` embeds four ECO targets named after a previous netlist
   (`_89776_/Y`, `ANTENNA_118/DIODE`, `fanout380/A`, `_89281_/Y`). Those names
   cannot be assumed stable across synthesis versions.
3. The archived `Final/sta_summary.rpt` and `Final/final/metrics.json` still
   contain 22 max-capacitance and 162 max-slew violations. Setup and hold are
   clean in those reports, which is different from complete electrical closure.
4. The required DEF template is a Git LFS object. The runner downloads just
   that input by immutable upstream commit and verifies its 2,407,774 bytes and
   SHA-256. Downloading archived output binaries is unnecessary.
5. Upstream does not lock the original LibreLane/tool versions. Selecting
   LibreLane 3.0.5 is an explicit reproduction hypothesis, not proof that it
   matches the original tapeout environment.

## Minimal functional repair

The original 4×4 testbench returns 28 passing words and 8 failures with seed 1.
Two independent issues were isolated:

- It puts the shift on the deprecated REQ instruction; the fused implementation
  consumes the CONV instruction's shift field.
- The CONV sub-FSM returns to idle while the main FSM waits two cycles for the
  fused datapath. Its level-sensitive EXECUTE condition starts the same CONV
  again. A trace showed four correct rows followed by four extra rows that
  overwrote the results while PC had advanced to REQ/ReLU/NOP.

The one-shot `exec_pulse` condition prevents replay. Golden arithmetic and
all original test vectors remain unchanged. Both seeds pass after this fix.
This is a repaired baseline, not an unchanged reproduction claim.

## Standalone floorplan comparison

`make pnr` (also available as `make pnr-standalone`) uses a
1,750 × 1,750 µm die and automatic pin placement, retaining the same repaired
RTL, 50 ns clock, SKY130 library and SDC files. It removes the fixed OpenFrame
DEF template. This macro does not fit the original OpenFrame physical slot.
The original-size experiment is retained as `make pnr-openframe`. That target
downloads the original DEF template and verifies its SHA-256 before use.

The larger floorplan became the default after it achieved zero routing DRC
while the original-size run terminated during its nineteenth routing iteration.
Its first post-route STA exposed an input hold violation of −0.273 ns. The
configuration now enables post-global-route timing repair with 0.5 ns hold
repair margin, retaining the original SDC requirements. These changes still
require a fresh complete validation; see `VALIDATION.md`.

## Subsequent gates

- V1: scan insertion, chain integrity, ATPG coverage/fault counts and explicit
  shift/capture constraints. Difetto is alpha, and its documented test-SDC
  limitation must be addressed before claiming test-mode signoff.
- V2: map Q/K/V, Q×Kᵀ and attention×V GEMMs with model-versus-RTL checks.
- V3: specify and verify numerical behavior for Softmax, LayerNorm and FFN.
- V4: repeat synthesis, DFT, routing, extraction and signoff after architecture
  changes. Do not carry old physical evidence forward as if it validated new RTL.

No placeholder `dft`, `atpg` or Transformer targets claim success in V0.
